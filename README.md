# REFERALS — Telegram-бот для взаємних рефералів

Користувачі виставляють анкети зі своїми реферальними посиланнями, виконують чужі завдання й отримують за це монети 🪙, а потім платять ними тим, хто виконав їхні завдання. Інтерфейс доступний трьома мовами: ru, uk, en. Адмін-панель українською.

## Стек
- Python 3.14 (версію задає файл `.python-version`), aiogram 3, aiohttp (вебхук), asyncpg, Pillow
- **Render** — хостинг (Web Service, вебхук)
- **Neon** — Postgres (дані, стани форм, налаштування)
- **UptimeRobot** — пінг `/health`, щоб Render не засинав

## Файли
| Файл | Що це |
|---|---|
| `main.py` | увесь бот: тексти, БД і міграції, монети, каталог, заявки, адмінка, фонові задачі |
| `requirements.txt` | точні версії бібліотек |
| `.python-version` | версія Python для Render |
| `*.png` | ілюстрації екранів, 1280×640 (можна перенести в папку `img/`, бот шукає там першою) |
| `DejaVuSans*.ttf` | шрифти для картинки зі статистикою в адмінці |

## Змінні середовища (Render → Environment)
| Змінна | Обов'язкова | Опис |
|---|---|---|
| `BOT_TOKEN` | так | токен від @BotFather |
| `DATABASE_URL` | так | рядок підключення Neon (`postgresql://…`); `channel_binding` бот прибирає сам |
| `ADMIN_IDS` | так | Telegram ID адмінів через кому |
| `BASE_URL` | ні | публічна адреса; на Render береться з `RENDER_EXTERNAL_URL` автоматично |
| `PORT` | ні | Render задає сам |

## Render
- Build command: `pip install -r requirements.txt`
- Start command: `python main.py`
- Health check path: `/health`

Під час запуску бот сам застосовує нові міграції БД і ставить вебхук `BASE_URL/webhook`.

## UptimeRobot
Монітор HTTP(s) на `https://<ваш-сервіс>.onrender.com/health` з інтервалом 5 хв.
- `200 ok` — усе добре.
- `503 database error …` — остання щогодинна перевірка Neon не пройшла.

`/health` навмисно не звертається до бази, щоб Neon міг засинати й не витрачати compute-години. Базу перевіряє фонова задача раз на годину.

## Адмінка
`/admin` — панель (статистика, користувачі, спори, чати, скарги, розсилка, налаштування).
`/user ID` або `/user @username` — картка, `/giveall N [причина]` — монети всім, `/ban ID`, `/unban ID`.
Усі числові правила (ціни, ліміти, бонуси, штрафи) змінюються в «⚙️ Налаштування» без деплою.

## Як змінювати базу
Міграції лежать у `main.py` (`M1_BASE`, `M2_COINS`, `M3_SAFETY`). Уже застосовані міграції не редагуйте. Для нових змін додайте `M4_…` у кінець списку `MIGRATIONS`.
